# Тукан Батл: запуск бесплатно (Render + GitHub)

Файлы: `server.py`, `index.html`, `cases.json`. Больше ничего не нужно. При обновлении заменяйте все три файла в репозитории.

## Шаги
1. **Токен.** В Telegram откройте @BotFather, отправьте `/newbot`, задайте имя и username, скопируйте токен.
2. **Ваш Telegram ID.** Напишите боту @userinfobot, он пришлёт число (ID). Затем откройте своего нового бота и нажмите `/start`. Это нужно для бэкапа баланса игроков.
3. **GitHub.** Создайте аккаунт на github.com, нажмите New repository (Public), затем «Add file → Upload files» и загрузите три файла, потом Commit.
4. **Render.** На render.com войдите через GitHub: New → Web Service → ваш репозиторий. Build Command оставьте пустым, Start Command: `python3 server.py`, Instance Type: Free.
5. **Переменные** (Environment):
   - `BOT_TOKEN`: токен из шага 1
   - `BACKUP_CHAT`: ваш ID из шага 2
   - `CHANNEL`: `@вашканал` (необязательно, для награды за подписку; бот должен быть админом канала)
   Нажмите Create Web Service.
6. **Адрес.** Когда деплой закончится, Render покажет адрес `https://....onrender.com`. Добавьте переменную `WEBAPP_URL` с этим адресом и сохраните (сервис перезапустится).
7. **Проверка.** Откройте бота, нажмите `/start` и «🦜 Играть».

## Как хранится баланс игроков
Бесплатный Render стирает файлы при каждом перезапуске и засыпании. Поэтому сервер каждые 5 минут (если что-то изменилось) и при остановке отправляет копию базы вам в личку в Telegram и закрепляет это сообщение. При новом запуске он сам забирает последнюю копию из закреплённого сообщения. Не удаляйте и не открепляйте эти сообщения. Если упадёт внезапно, потеряются изменения максимум за 5 минут.

## Сон
Через 15 минут без заходов сервис засыпает, пробуждение около минуты. Пока он спит, `/start` в боте не отвечает. Кнопка «Играть» в меню бота его будит.

## Переменные окружения (полный список)
- `BOT_TOKEN` — токен бота (обязательно)
- `WEBAPP_URL` — адрес сервиса на Render
- `BACKUP_CHAT` — ваш Telegram ID (куда уходят копии базы)
- `CHANNEL` — `@канал` для обязательной подписки (бот должен быть админом канала)
- `ADMIN_IDS` — ID админов через запятую (если не задано, админом считается `BACKUP_CHAT`)

## Админка
Работает командами в чате с ботом, только для админов. Откройте бота и отправьте `/admin`: бот пришлёт список всех команд и кнопки быстрого доступа (статистика, топ, оплаты, промокоды). Команда `/refs ID|@ник` показывает приглашённых игроком.

## Награды
Стартовый баланс 0 ★. За подписку на канал и за каждого реферала (нажал старт и подписался) начисляется 5 ★. Кликер закрыт.

## Промокоды
Админ создаёт: `/promoadd КОД ★ макс_использований [дней]`. Игроки активируют: `/promo КОД`.

## Магазин за звёзды
- Пополнение: от 25 до 10 000 ⭐, курс 1 ⭐ = 1 ★ (`STAR_RATE`, по умолчанию 1). ★ — внутриигровая валюта, вывода и обмена на деньги или Stars нет.
- `SUPPORT_CONTACT` — ваш контакт для поддержки, например `@username` (показывается в `/support`, `/paysupport`).
- Админ-команды: `/payments` (последние оплаты), `/refund CHARGE_ID` (вернуть звёзды игроку и отменить покупку).
- Вывод звёзд владельцем: в Telegram откройте профиль бота в BotFather или Settings → My Stars → ваш бот → Withdraw (нужны 1000 ⭐, звёздам не менее 21 дня, включённая двухэтапная проверка).
